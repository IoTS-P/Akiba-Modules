# StringBaseFinder

## Category

- General

## Description

Find the base address of a firmware by matching string addresses

### Database columns

- 🟢 `BASE_ADDRESS INTEGER`: Base address got.

## Mechanism

The steps can be concluded in:

1. Get all scalars in a firmware
2. Cluster scalars into groups
3. Select largest groups to build subtraction maps
4. Get the most possible base address

### 1. Get all scalars in a firmware

To simplify the process of binary analysis, we use the pseudo-C code of every function generated by Ghidra to extract all constant values(scalars) in every function, and aggregate them into a set.

### 2. Cluster scalars into groups

Considering that scalars are not all actual addresses, we need to cluster them into groups. Those adjacent values are likely to be in the same group.

We use HDBSCAN clustering algorithm to cluster scalars, the default epsilon is 0x40000 (4MiB space, should be enough for most firmwares to save strings)

### 3. Select largest groups to build subtraction maps

When we get the clusters, we need to select those largest groups to build subtraction maps. In some large firmwares, the number of strings and scalars could be large, building a complete subtraction map for large dataset is very time-consuming and memory-consuming, so for firmwares that has more than 500 strings or more than 500 scalars, we will randomly select 500 strings and 500 scalars to build subtraction maps(the selection could perform multiple times to eliminate occasionality as much as possible).

### 4. Get the most possible base address

We can see through subtraction maps to see which difference has repeated most often, which is the feature of the most possible base address.
